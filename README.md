# Spinoff พ่อบ้านจอมมาร

## เปิดอ่านและฟังบนเว็บ

**[อ่าน e-book พ่อบ้านจอมมาร SPINOFF](https://mayukumazaki.github.io/demon-butler-spinoff-ebook/)**

มังงะครบ **1,404 หน้า** พร้อมคำแปลไทยและไฟล์เสียงพากย์สำเร็จรูป เลือกช่วงหน้า ข้ามไปหน้าที่ต้องการ ฟังทีละหน้า หรือเปิดอ่านอัตโนมัติเพื่อฟังต่อเนื่องได้ โดยไม่ต้องลงชื่อเข้าใช้

## ไฟล์ฉบับครบ

[ดาวน์โหลดแพ็กเกจฉบับครบจาก Releases](https://github.com/mayukumazaki/demon-butler-spinoff-ebook/releases/tag/ebook-1404-v1)

ภาพต้นฉบับทั้งหมดถูกเก็บไว้ในแพ็กเกจโดยไม่แก้ไข เว็บใช้ไฟล์เสียงสำเร็จรูป ไม่เรียกบริการสร้างเสียงระหว่างอ่าน

## การเผยแพร่และตรวจสอบ

GitHub Pages ใช้ workflow **Publish complete e-book** จาก branch **main** ดาวน์โหลดแพ็กเกจ Release ตรวจ SHA-256 และตรวจภาพ คำแปล และไฟล์เสียงครบทุกหน้าก่อนเผยแพร่

หากต้องเผยแพร่ชุดเดิมใหม่: Actions → Publish complete e-book → Run workflow → main. ไม่ต้องเปลี่ยนกฎป้องกัน environment หรือสร้างรหัส API ใหม่
